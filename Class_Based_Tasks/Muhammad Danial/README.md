# NACTTAC Training — Week and Class Organization

The training assignments are organized into six weekly folders, each containing four class folders: **Class 1, Class 2, Class 3, and Class 4**. Each task appears only once and is placed in the class that best matches the topic sequence.

## Weekly Task Allocation

| Week | Tasks | Topics |
|---|---|---|
| **Week 1** | 1–27 | Software installation, shell commands, Python fundamentals, control flow, collections, functions, and exception handling |
| **Week 2** | 49–50 | Descriptive statistics: mean, median, mode, and standard deviation |
| **Week 3** | 28–40 | NumPy arrays, indexing, slicing, data types, reshaping, iteration, and array operations |
| **Week 4** | 41–48 | Pandas fundamentals, Series, DataFrames, CSV files, data analysis, cleaning, and correlation |
| **Week 5** | 51–52 | Linear regression and logistic regression |
| **Week 6** | 53–55 | Decision-tree classification, Support Vector Machines (SVM), and time-series analysis |

## Organization Notes

- Duplicate tasks from the original Class 1–4 folders have been removed.
- Each task is included once within its assigned week and class.
- **Task 20** is placed in Week 1 to keep all 27 Python assignments together.
- The source archive contains no standalone task files numbered **56 onward**.
