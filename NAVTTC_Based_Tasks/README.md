# NAVTTC-Based Tasks

This folder contains official NAVTTC assignment submissions for all students in Batch 8.

## Instructions

* Each student must create a personal folder using their full name.
* Inside their folder, organize assignments into `Week_1`, `Week_2`, `Week_3`, `Week_4`, and `Week_5`.
* Upload all assigned NAVTTC tasks.
* Use clear filenames and submit the correct files in the appropriate week folder.
